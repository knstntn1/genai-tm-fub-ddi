# Quick Task 20260507: Dataset Management Summary

## Outcome

Implemented project-owned dataset management with a top AppBar `DataExplorer` entry point.

Users can now:

- Open DataExplorer from the top bar next to Open and Save.
- Create and delete project-owned datasets.
- Add images to datasets through upload, webcam capture, and OpenVerse search.
- Tag each dataset image as exactly one of `training` or `test`.
- Persist managed datasets inside the project ZIP when samples are saved.
- Load managed datasets back from the project ZIP.
- Use managed `training` images in the existing training dataset picker.
- Use managed `test` images in the existing test dataset picker.

## Implementation Notes

- Added `datasetState`, `showDataExplorer`, and project dataset domain types in `src/state.ts`.
- Added ZIP manifest/image helpers in `src/util/projectDatasets.ts`.
- Extended `ModelSaver` and `ModelLoader` for optional project dataset persistence.
- Added `DataExplorerDialog` and locale keys across `image_adv.json` files.
- Extended `DatasetPicker` and `DatasetTestPicker` with canvas-backed managed image support while preserving remote URL-backed dataset behavior.
- Fixed review blockers:
  - DataExplorer mutations now mark the project dirty.
  - Managed datasets follow the save-samples contract.
  - Optional dataset ZIP failures no longer make the core project unloadable.
  - DataExplorer locale check mode is read-only.
