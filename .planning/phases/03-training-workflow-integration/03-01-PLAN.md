<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OpenVerse result -> browser UI | Untrusted result URLs and titles enter rendered dialog tiles. |
| Remote image host -> canvas importer | Untrusted remote image bytes are loaded, decoded, drawn, and read back in the browser. |
| Async import callback -> class state | A slow result selection attempts to mutate local class sample state after user edits may have changed class identity. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | T | `Classification.handleUseOpenVerseImage` | mitigate | Mutate class state only after `importOpenVerseImage` returns a readable canvas and the captured class label still matches. |
| T-03-02 | R | `OpenVerseSearchDialog` integration | mitigate | Rejected importer/stale errors must render existing failed-use state and leave samples unchanged; tests assert unchanged arrays. |
| T-03-03 | I | `Classification.tsx`, locale files | mitigate | Do not render OpenVerse provenance/license/source/creator/mature/filter fields in the class workflow; grep gate verifies no visible metadata/filter terms. |
| T-03-04 | D | `importOpenVerseImage` caller | mitigate | Pass `AbortController.signal`, abort superseded/unmounted imports, and rely on Phase 1 timeout/bounds. |
| T-03-05 | E | `TrainingData.setDataIx` | mitigate | Reject invalid class indexes by returning old state unchanged before calling the updater. |
</threat_model>
