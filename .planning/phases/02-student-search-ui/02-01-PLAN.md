```typescript
export interface OpenVerseImageResult {
    id: string;
    title: string;
    imageUrl: string;
    thumbnailUrl: string;
    width?: number;
    height?: number;
    source?: string;
    foreignLandingUrl?: string;
    license?: string;
    licenseUrl?: string;
    creator?: string;
    mature?: boolean;
}

export interface OpenVerseImageSearchResult {
    results: OpenVerseImageResult[];
    page: number;
    pageCount: number;
    pageSize: number;
    resultCount: number;
}

export interface SearchOpenVerseImagesOptions {
    query: string;
    page?: number;
    pageSize?: number;
    signal?: AbortSignal;
}

export class OpenVerseSearchError extends Error {
    readonly code: OpenVerseSearchErrorCode;
    readonly status?: number;
    readonly retryAfter?: string;
}

export async function searchOpenVerseImages(
    options: SearchOpenVerseImagesOptions
): Promise<OpenVerseImageSearchResult>;
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Student input -> OpenVerse search client | Untrusted classroom query text enters a browser API request. |
| OpenVerse response -> React UI | Untrusted remote result data and URLs are rendered as image thumbnails and accessible labels. |
| Result activation -> parent callback | Remote result object crosses from the dialog into future Phase 3 integration through `onUseImage`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | T | `OpenVerseSearchDialog.tsx` search handler | mitigate | Trim and block empty queries before calling `searchClient`; pass the query only through the typed Phase 1 client that enforces `mature=false`. |
| T-02-02 | I | result grid rendering | mitigate | Render only thumbnail images and the localized action overlay; never render license, creator, source, URL, dimensions, mature controls, or attribution metadata visibly in Phase 2. |
| T-02-03 | D | async search/pagination | mitigate | Disable duplicate submit/loading-more buttons, abort prior requests, and ignore stale request IDs after close or new search. |
| T-02-04 | E | result activation callback | mitigate | Keep Phase 2 callback neutral and local; do not import class state or mutation helpers, and verify with grep gates. |
| T-02-05 | R | failed result use | mitigate | Show local failed-use state when `onUseImage` rejects so the UI does not claim success or hide failures. |
</threat_model>
